# Allan Lo 和你逛文化

導覽員 **Allan Lo** 與 AI 小助手 **阿拉蕾** 帶你逛臺灣各縣市的文化資產。這是一個知性與旅遊資訊網站，用地圖、雙人語音故事、老地圖時光機、行程規劃和知識遊戲介紹文化資產。

- 規劃設計：Allan Lo，https://www.123hi.org，2026年11月
- 使用 AI 工具：Claude Opus 5.5

目前開放 **嘉義市**（`chiayi-city/`）、**嘉義縣**（`chiayi-county/`）、**雲林縣**（`yunlin-county/`）、**臺南市**（`tainan-city/`）、**高雄市**（`kaohsiung-city/`）、**屏東縣**（`pingtung-county/`）、**臺東縣**（`taitung-county/`）、**澎湖縣**（`penghu-county/`）、**金門縣**（`kinmen-county/`）、**宜蘭縣**（`yilan-county/`）、**花蓮縣**（`hualien-county/`）、**基隆市**（`keelung-city/`）與 **連江縣（馬祖）**（`lienchiang-county/`）。每個縣市各有一個資料夾，網頁程式全部共用；新增縣市只要準備資料（見下方「新增縣市」）。

GitHub Pages 每個網站上限 1 GB，所以網站分成兩個 repo：本 repo（第一網站，https://allanloplus.github.io/Cultural_Heritage/）放全站首頁、共用程式、工具與上面 13 個縣市；臺北市、新北市、桃園市、新竹市、新竹縣、苗栗縣、臺中市、彰化縣、南投縣放 [第二網站 allanloplus/Cultural_Heritage2](https://github.com/allanloplus/Cultural_Heritage2)（https://allanloplus.github.io/Cultural_Heritage2/）。第二網站只放縣市資料夾，縣市頁從第一網站載入共用程式；入口頁、選單會自動連到正確的網站，文資護照可以跨網站使用。詳見作業手冊〈兩個網站〉。

## 修改內容與重新產生

需要 Python 3、`pip install edge-tts pillow`、ffmpeg。

```bash
python3 tools/build_data.py
```

```bash
python3 tools/gen_audio.py
```

`gen_audio.py` 只會重新合成內容有變動的句子。

| 檔案 | 內容 |
|---|---|
| `<縣市>/data/config.json` | 縣市設定：地圖中心與縮放、類別、鄉鎮、YouBike 區碼、各時期要疊的老地圖、行程速度與提醒、頁面文字 |
| `<縣市>/data/sites-official.json` | 文化部文化資產局開放資料：名稱、類別、鄉鎮、地址、座標、官方連結 |
| `<縣市>/data/sites-content.json` | 每個景點的介紹、重點、冷知識、雙人對話、猜謎線索、測驗；`lat`/`lng` 為核對後的座標（官方座標有誤時會修正並在 `coordNote` 說明） |
| `<縣市>/data/eras.json` | 時光地圖各時期內容、地標座標（嘉義市另有清代城牆推定範圍） |
| `<縣市>/data/ich.json` | 無形文化資產、民俗與古物，以及它們的公開展示地點 |
| `<縣市>/data/images.json` | Wikimedia Commons 照片與授權 |
| `<縣市>/data/ubike.json` | YouBike 2.0 站點快照 |
| `<縣市>/data/extra.json` | 開場與說明對話、遊戲回饋語音、推薦行程、出發點 |
| `tools/portal.json` | 入口頁對話。這段文字也寫在 `index.html` 裡，兩邊要一致。 |
| `tools/city_template.html` | 各縣市頁面的共用版型（`{{root}}`＝共用資源路徑：第一網站 `../`，第二網站 `/Cultural_Heritage/`） |
| `tools/sites.py` | 兩個網站的對應：縣市在哪個 repo（依 `assets/js/cities.js` 的 `site` 欄位） |
| `assets/js/city/`、`assets/css/city.css` | 各縣市共用的網頁程式與樣式 |

改完 JSON 後，執行 `build_data.py` 會產生每個縣市的 `js/data.js` 與 `index.html`，以及 `tools/script.json`（語音腳本）。第二網站的縣市也由這裡的工具產生，寫到 `Cultural_Heritage2` 的 clone（預設在本 repo 旁邊，或用環境變數 `CH2_DIR` 指定）。

照片副本用 `python3 tools/fetch_images.py <縣市資料夾>` 下載到該縣市的 `img/`。沒有下載到的照片，網頁會直接連結 Wikimedia Commons。

### 新增縣市

完整流程、工具與規則請看 **[`tools/newcity/README.md`（新增縣市作業手冊）](tools/newcity/README.md)**，內容撰寫規格在 `tools/newcity/SPEC.md`，派給內容 agent 的指示範本在 `tools/newcity/PROMPTS.md`。簡要步驟：

1. `tools/newcity/fetch_sources.py` 下載文資局開放資料、YouBike 站點與維基百科列表。
2. 寫 `<縣市>/data/config.json`，用 `tools/newcity/build_base.py` 產生景點清單、官方資料與 YouBike 站點，用 `tools/newcity/images.py` 與 `tools/fetch_images.py` 處理照片。
3. 分批派內容 agent 撰寫景點、時光地圖與無形文化資產，用 `tools/newcity/merge.py` 檢查並合併。
4. 寫 `extra.json`（開場對話、遊戲反應、出發點、推薦行程），執行 `python3 tools/build_data.py` 與 `python3 tools/gen_audio.py`。
5. 在 `assets/js/cities.js` 把該縣市設為開放（`on: true`、`slug`、代表照片），更新入口頁問候語與語音。入口頁的卡片、地圖、右上角功能表，以及各縣市頁的「切換縣市」選單都會自動更新。
6. 用 `tools/newcity/tests/` 的瀏覽器測試驗收。

## 本機預覽與上線

純靜態網站，不需要後端。

```bash
python3 tools/serve.py
```

開啟 http://localhost:8000/Cultural_Heritage/ 即可預覽。這個伺服器和 GitHub Pages 一樣，用 `/Cultural_Heritage/` 與 `/Cultural_Heritage2/` 兩個路徑同時提供兩個網站（第二網站的縣市頁用絕對路徑載入共用程式，要用這種網址才看得到）。這個預覽伺服器支援 HTTP Range，語音可以跳句。Python 內建的 `python3 -m http.server` 不支援 Range，用它預覽時按「下一句」會從頭播放；GitHub Pages 沒有這個問題。

上線用 GitHub Pages：兩個 repo 都是 Settings → Pages → Deploy from a branch，選 `main` 與 `/ (root)`。開發在各 session 的工作分支進行，每完成一個縣市建立 PR，合併到 `main` 後才上線（見 `tools/newcity/README.md`〈發布流程〉）。GitHub Pages 每個網站上限 1 GB，兩個網站各自計算，目前用量與門檻見作業手冊〈容量管理〉，可隨時執行 `python3 tools/newcity/size_report.py` 查看。
