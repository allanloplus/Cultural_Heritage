# Allan Lo 和你逛文化

導覽員 **Allan Lo** 與 AI 小助手 **阿拉蕾** 帶你逛臺灣各縣市的文化資產。這是一個知性與旅遊資訊網站，用地圖、雙人語音故事、老地圖時光機、行程規劃和知識遊戲介紹文化資產。

- 規劃設計：Allan Lo，2026/11/1
- 使用 AI 工具：Claude Opus 5.5

目前開放 **嘉義市**（`chiayi-city/`）、**嘉義縣**（`chiayi-county/`）、**雲林縣**（`yunlin-county/`）與 **臺南市**（`tainan-city/`）。每個縣市各有一個資料夾，網頁程式全部共用；新增縣市只要準備資料（見下方「新增縣市」）。

## 語音

語音沿用課程網站的做法，用 Microsoft Edge 神經網路語音預先合成：

- Allan：`zh-TW-YunJheNeural`（台灣男聲）
- 阿拉蕾：`zh-TW-HsiaoYuNeural`，音調調高（台灣小女生）

每段對話合成一個 mp3，存在各縣市的 `audio/`（例如 `chiayi-city/audio/`）。`cues.js` 記錄每句的起訖時間與內容雜湊。如果文字改了但語音還沒重新產生，播放器會自動改用瀏覽器內建語音。

## 修改內容與重新產生

需要 Python 3、`pip install edge-tts pillow`、ffmpeg。

```bash
python3 tools/build_data.py
```

```bash
python3 tools/gen_audio.py
```

`gen_audio.py` 只會重新合成內容有變動的句子。

| 檔案 | 內容 |
|---|---|
| `<縣市>/data/config.json` | 縣市設定：地圖中心與縮放、類別、鄉鎮、YouBike 區碼、各時期要疊的老地圖、行程速度與提醒、頁面文字 |
| `<縣市>/data/sites-official.json` | 文化部文化資產局開放資料：名稱、類別、鄉鎮、地址、座標、官方連結 |
| `<縣市>/data/sites-content.json` | 每個景點的介紹、重點、冷知識、雙人對話、猜謎線索、測驗；`lat`/`lng` 為核對後的座標（官方座標有誤時會修正並在 `coordNote` 說明） |
| `<縣市>/data/eras.json` | 時光地圖各時期內容、地標座標（嘉義市另有清代城牆推定範圍） |
| `<縣市>/data/ich.json` | 無形文化資產、民俗與古物，以及它們的公開展示地點 |
| `<縣市>/data/images.json` | Wikimedia Commons 照片與授權 |
| `<縣市>/data/ubike.json` | YouBike 2.0 站點快照 |
| `<縣市>/data/extra.json` | 開場與說明對話、遊戲回饋語音、推薦行程、出發點 |
| `tools/portal.json` | 入口頁對話。這段文字也寫在 `index.html` 裡，兩邊要一致。 |
| `tools/city_template.html` | 各縣市頁面的共用版型 |
| `assets/js/city/`、`assets/css/city.css` | 各縣市共用的網頁程式與樣式 |

改完 JSON 後，執行 `build_data.py` 會產生每個縣市的 `js/data.js` 與 `index.html`，以及 `tools/script.json`（語音腳本）。

照片副本用 `python3 tools/fetch_images.py <縣市資料夾>` 下載到該縣市的 `img/`。沒有下載到的照片，網頁會直接連結 Wikimedia Commons。

### 新增縣市

1. 建立資料夾（例如 `changhua-county/`），在 `data/` 放入上表的 JSON 檔（可參考 `chiayi-county/data/`）。
2. 執行 `python3 tools/build_data.py` 與 `python3 tools/gen_audio.py`。
3. 在 `assets/js/cities.js` 的縣市清單把該縣市設為開放（`on: true`、`slug`、代表照片）。入口頁的卡片、地圖、右上角功能表，以及各縣市頁的「切換縣市」選單都會自動更新。

## 本機預覽與上線

純靜態網站，不需要後端。

```bash
python3 tools/serve.py
```

開啟 http://localhost:8000 即可預覽。這個預覽伺服器支援 HTTP Range，語音可以跳句。Python 內建的 `python3 -m http.server` 不支援 Range，用它預覽時按「下一句」會從頭播放；GitHub Pages 沒有這個問題。

上線用 GitHub Pages：Settings → Pages → Deploy from a branch，選要發布的分支與 `/ (root)`。

## 資料來源與授權

- **文化資產資料**：[文化部文化資產局開放資料](https://data.boch.gov.tw/)、[國家文化資產網](https://nchdb.boch.gov.tw/)（政府資料開放授權條款）。另外與維基百科「[臺南市文化資產](https://zh.wikipedia.org/zh-tw/%E8%87%BA%E5%8D%97%E5%B8%82%E6%96%87%E5%8C%96%E8%B3%87%E7%94%A2)」「[雲林縣文化資產](https://zh.wikipedia.org/zh-tw/%E9%9B%B2%E6%9E%97%E7%B8%A3%E6%96%87%E5%8C%96%E8%B3%87%E7%94%A2)」「[嘉義市文化資產](https://zh.wikipedia.org/zh-tw/%E5%98%89%E7%BE%A9%E5%B8%82%E6%96%87%E5%8C%96%E8%B3%87%E7%94%A2)」「[嘉義縣文化資產](https://zh.wikipedia.org/zh-tw/%E5%98%89%E7%BE%A9%E7%B8%A3%E6%96%87%E5%8C%96%E8%B3%87%E7%94%A2)」比對過清單。座標另以 OpenStreetMap 核對，官方座標有誤者已修正。
- **照片**：Wikimedia Commons 的自由授權照片（CC BY、CC BY-SA、公有領域、CC0）。網頁上都有標示作者、授權與原始頁面連結。沒有自由授權照片的景點，只用連結指向官方代表圖或搜尋結果。
- **老地圖**：[中央研究院人社中心 臺灣百年歷史地圖](https://gis.sinica.edu.tw/tileserver/)。
- **底圖**：內政部國土測繪中心（通用電子地圖、正射影像）、OpenStreetMap。
- **路線**：FOSSGIS OSRM（routing.openstreetmap.de）。服務連不上時，改用直線距離估算。
- **YouBike**：YouBike 微笑單車官方站點資料。站點位置用快照，即時車輛在網頁上查詢。
- **角色**：Allan Lo 與阿拉蕾的角色圖由委託人提供，裁切去背後存放在 `assets/characters/`。

使用提醒：開放時間、導覽場次常有調整，請以各管理單位的公告為準。私人宅第、宿舍與仍在使用的宗教場所，請在公共空間欣賞外觀，不要擅自進入。

護照、造訪紀錄、自選景點只存在使用者自己的瀏覽器（localStorage），不會上傳。
